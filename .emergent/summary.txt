<product_requirements>
The goal is to build an AI-assisted Custom ERP for Grain Trading, Custody, and Funding for Sudarshan Trading Company. This modular, multi-user ERP needs responsive web screens, an admin portal, dashboards, QR-based weighbridge automation, and custody funding workflow with LTV monitoring. Key modules include Farmer Purchase, Bill Purchase, Production, Sales, Accounts, Weighbridge Pre-Entry, and Custody & Pledge Funding. AI integration is required for smart alerts and recommendations for margin calls, using Gemini 2.5 Pro. Authentication is simple login initially, with no external integrations prioritized at the start. Database is MongoDB, frontend React, backend FastAPI. Branding uses grain/agriculture-inspired colors (olive green, brown, harvest gold).

The detailed Farmer Payment module requires a single-page form with weighbridge pre-entry integration (Gate Entry No.) to fetch data and display two weighment photos for operator approval. Approved slips auto-fill farmer, vehicle, item, and weight details. It includes H+T calculation logic based on vehicle type (deducted from item amount), multi-item support, and partial cash/bank payments. On save, it must create linked Purchase and Payment Vouchers to ledgers. Printing requires a bilingual PDF.
</product_requirements>
